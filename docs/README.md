# Электричество и магнетизм — учебный сайт

## Запуск

1. Распакуйте папку проекта целиком.
2. Откройте `index.html` в современном браузере.
3. Интернет не обязателен для работы логики и визуализаций. Подключение к интернету используется только для загрузки веб-шрифтов; при отсутствии сети будут использованы системные шрифты.

Проект не использует сборщик и npm. MathJax 3.2.1 включён локально в `assets/vendor/mathjax/`, поэтому формулы LaTeX отображаются без подключения к интернету. Сайт можно открыть напрямую через `file://`. Для SVG-рендеринга формул используется MathJax; исходный текст новых формул нужно сохранять в LaTeX.

## Как добавить новую страницу

1. Скопируйте любой файл из `content/` и переименуйте его, например `07-magnetic-field.js`.
2. Оставьте структуру объекта `window.EM_TOPICS.push({...})`, но замените содержание.
3. Выдайте новой странице уникальный `id` (латиница, дефисы), номер, главу, заголовок и теги.
4. В `index.html` добавьте перед `assets/js/app.js` новую строку:

```html
<script src="content/07-magnetic-field.js"></script>
```

5. Сохраните файлы и перезагрузите страницу. Новая тема появится в боковом содержании.

Порядок `<script>` в `index.html` определяет порядок страниц в навигации. Поле `chapter` задаёт группу в меню.

## Формат одной темы

Каждый файл темы добавляет один объект в массив `window.EM_TOPICS`. Поддерживаемые поля:

- `id`, `number`, `chapter`, `title`, `tags`, `level`, `lead`;
- `definition`, `objectives`;
- `sections`: массив разделов с `id`, `title`, `body`, `list`, `definition`, `formulas`, `note`;
- `visuals`: конфигурации встроенных интерактивных моделей;
- `examples`: задачи с пошаговым решением;
- `quiz`: тестовые вопросы с вариантами и объяснением ответа;
- `takeaways`: краткие итоги.

В текстовых полях допускается базовая HTML-разметка: `<b>`, `<i>`, `<sub>`, `<sup>`, `<code>`, `<span>`, `<br>`. Для inline-формул используйте `\(...\)`, для отдельной формулы — `\[...\]`. В `sections[].formulas[].formula` записывается чистый LaTeX-код без разделителей; оболочка сайта автоматически помещает его в display math. Не вставляйте скрипты и обработчики событий в содержимое темы.

## Доступные типы визуализаций

На текущем этапе доступны: `charge`, `coulomb`, `superposition`, `gauss`, `potential`, `dipole`, `conductor`, `dielectric`, `capacitor`, `circuit`. Математические выражения отображаются локальным MathJax в SVG-формате.

Пример:

```js
visuals: [{
  type: 'coulomb',
  title: 'Закон Кулона',
  description: 'Изменяйте заряды и расстояние между ними.'
}]
```

Если тип неизвестен, вместо модели появится нейтральная заглушка. Для принципиально новой модели требуется добавить обработчик в `initVisuals()` файла `assets/js/app.js`.

### Границы физических моделей

Модели предназначены для изучения зависимостей, а не для замены полноценного численного симулятора. Их предположения:

- `charge` — качественное изображение радиального поля одиночного точечного заряда; число линий условно отражает модуль заряда.
- `coulomb` — два точечных неподвижных заряда; рассчитывается модуль силы и показывается направление сил на каждом заряде.
- `superposition` — два заряда на одной прямой, точка наблюдения находится ровно посередине; вычисляются знаковые x-компоненты двух полей и их сумма.
- `gauss` — точечный заряд в центре сферической гауссовой поверхности; поток равен `q/ε₀`, а поле на сфере рассчитывается как `k|q|/r²`.
- `potential` — график потенциала точечного заряда `φ(r)=kq/r` и модуль поля `k|q|/r²`.
- `dipole` — пара равных по модулю точечных зарядов `+q` и `−q`; линии строятся численным трассированием направления результирующего поля.
- `conductor` — изолированный сферический проводник с равномерным поверхностным зарядом; внешнее поле показано качественно, внутри материала `E=0`.
- `dielectric` — линейный изотропный диэлектрик между плоскими обкладками при фиксированной свободной плотности заряда; краевыми эффектами пренебрегаем.
- `capacitor` — идеальный плоский конденсатор; краевые эффекты не учитываются, расчёт использует `C=ε₀εᵣS/d`.
- `circuit` — идеальный источник напряжения и один резистор без внутреннего сопротивления источника и сопротивления проводов.

Удлинение стрелок и число линий в схемах — визуальные индикаторы, а не самостоятельные точные физические величины. Численные значения в блоках результатов рассчитываются по формулам, указанным для каждой модели.

## Прогресс

Отметки «Изучено» сохраняются в `localStorage` данного браузера. Это локальный прогресс одного браузерного профиля, а не синхронизация между устройствами.

## Дизайн интерфейса

Сайт использует светлую тему в стиле технической документации с крупной типографикой, левой навигацией по курсу и правым оглавлением текущей страницы. Параметры оформления находятся в `assets/css/styles.css`; новые страницы контента не должны добавлять собственные стили. Подробнее: [`DESIGN_GUIDE.md`](DESIGN_GUIDE.md).
