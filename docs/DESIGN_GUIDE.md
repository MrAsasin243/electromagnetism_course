# Дизайн-система курса «Электричество и магнетизм»

Интерфейс оформляется как техническая документация для инженерного курса. Визуальная задача — обеспечить длительное чтение, быстрое ориентирование в структуре и ясное отделение основного материала от служебных элементов.

## Направление

- Строгая нейтральная палитра: белый фон, светло-серая навигация, графитовый текст.
- Один сдержанный сине-серый акцент для текущего пункта меню, ссылок и управляющих элементов.
- Минимум декоративных карточек, теней, градиентов и скруглений.
- Тонкие разделители и моноширинные номера для технической структуры.
- Основная статья — главный визуальный объект страницы.

## Сетка

- Левая панель: глобальная навигация по курсу, поиск и прогресс.
- Верхняя панель: короткие хлебные крошки и управление размером текста.
- Центральная колонка: содержание текущей темы, ориентир 760–830 px.
- Правая колонка: содержание статьи и учебные цели; остаётся на месте при прокрутке.
- На узком экране правая колонка перемещается над статьёй, левая становится выдвижной.

## Типографика

- Основной текст: 16–17 px, межстрочный интервал около 1.75.
- Заголовок темы: 32–39 px.
- Заголовки подразделов: 19–23 px.
- Подписи, номера и служебные метки: 9–12 px; они не должны заменять основной текст.
- Формулы: отдельные блоки с горизонтальной прокруткой при необходимости.

## Компоненты содержимого

- Определение: нейтральный блок с тонкой левой линией.
- Замечание: спокойный тёплый фон, без ярких предупреждающих плашек.
- Формула: светлая техническая подложка, заметный набор LaTeX, краткая подпись и пояснение.
- Пример: отделение тонкой линией, пошаговое решение без лишней карточной рамки.
- Интерактивная модель: отдельная рабочая область с тёмным контрастным полем модели и расположенными ниже параметрами.
- Тест: компактный список вариантов с явным состоянием правильного/неправильного ответа.

## Ограничения для новых страниц

Новые файлы тем не должны добавлять собственные стили, цветовые схемы или декоративные карточки. Используйте компоненты, предусмотренные `assets/js/app.js`, и придерживайтесь этого руководства.
